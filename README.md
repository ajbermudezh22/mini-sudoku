# Mini Sudoku

A 4×4 sudoku you can solve in a minute.

A small demo app from the **Agents Live** station at the AI Studio, Lift Conference 26 (6./7. November).
Visitors say what it should do next, and Claude Code adds the feature live.

**Try it:** https://ajbermudezh22.github.io/mini-sudoku/

## Make it your own
1. Fork this repo.
2. Open it with an AI coding agent (for example Claude Code) and ask for a feature in plain words.
3. Open the page in your browser: `npx live-server` or just open `index.html`.

Plain HTML, CSS and JavaScript. No build step.
